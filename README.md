# LifeBuddy

> 把散落的经历，变成随时能用的自己。

LifeBuddy 是一个帮你**记录、整理并复用个人经历**的智能助手。你只要像平时一样聊天，它会替你记住说过的事；等到要写简历、要查资料、要回想自己做过什么时，这些积累就能直接派上用场。

界面左侧是四个入口 —— **智能对话**、**个人档案**、**知识库**、**简历中心**，随用随切。

---

## 它能帮你解决什么

| 你遇到的情况 | LifeBuddy 怎么做 |
| --- | --- |
| 做过的事太多，过段时间连自己都记不清 | 聊天时随口提到的技能、项目、偏好会被自动沉淀下来，随时可查 |
| 每次写简历都要从头翻聊天记录、翻旧文件 | 所有经历持续累积在档案里，生成简历时一次取用，一项不漏 |
| 投不同岗位，简历得反复改说法 | 贴上招聘信息，自动生成用词贴合这个岗位的简历 |
| 资料存了一堆，真要找某句话时翻不到 | 把自己的文档传进知识库，直接提问，答案还会标明出自哪份文件 |
| 担心 AI 把别人的经历安到自己头上 | 聊到个人信息时只依据已记录的档案作答；知识查询只依据你上传的资料，没有就明确说没有 |
| 聊久了上下文混在一起，越聊越乱 | 一键清空会话，重新开启一轮干净对话 |
| 信息变了、之前记错了 | 档案可逐条修改或删除，同类信息自动合并，不留自相矛盾的旧记录 |

## 四个地方，四件事

### 智能对话

像和朋友聊天一样说话就行。它能陪你闲聊、回答常识问题，也会在对话中**自动记住**你提到的技能、经历与偏好，并轻轻提示你「已自动更新个人档案」。聊到自己的过往时，它只依据已经记录的内容回答，不会凭空替你编一段经历。

- 回答逐字呈现，不用盯着空白等结果
- 涉及更正或补充时更新原有记录，不会越记越重复
- 「清空会话」彻底清掉当前上下文与历史，重新开一轮
- 也可以直接在这里让它帮你写一份简历

### 个人档案

聊天里沉淀下来的信息，会按 **基本信息 / 技能 / 教育经历 / 项目经验 / 工作经历 / 个人偏好 / 其他** 七类自动归好，不需要你维护任何表格。

- 按分类筛选浏览，每条都标了来源与记录时间
- 说错了、换工作了，直接编辑或删除那一条
- 相似内容自动合并，避免同一件事换种说法反复堆积
- 「刷新档案」随时拉取最新内容

### 知识库

把自己写的笔记、旧简历、学习资料传进去，之后就能针对这些资料提问。

- 「知识查询」是独立的问答窗口：**只依据你上传的文档回答**，并标出答案来自哪个文件
- 资料里没有的内容会明确告知，不会拿通用知识凑一个答案
- 上传的文件可查看收录状态，随时删除
- 关掉查询窗口不保留聊天记录，下次打开就是全新一轮

### 简历中心

投不同岗位不用从头改简历。填上**目标职位名称**和**招聘信息（JD）**，LifeBuddy 会结合你档案里的全部经历，生成一份贴合这个岗位的简历。

- 所有任职经历与项目**完整列出**，不为精简而漏掉；描述用词往岗位要求上靠
- 固定为「姓名 / 求职意向 / 个人评价 / 技能与证书 / 工作项目经历」，求职意向自动填好
- 个人评价讲的是「你具备哪些能力」，项目部分才展开具体做过什么
- 生成记录可随时查看、导出为 Markdown 文件、删除

## 用起来是什么样

1. 想不起两年前那个项目具体做了什么 —— 在对话里随口提一句，之后档案里就一直有。
2. 准备投一个心仪岗位 —— 把招聘信息贴进简历中心，很快拿到一份按岗位说法重写、所有项目都在的简历。
3. 手里攒了一堆学习笔记 —— 传进知识库，直接问「我当时记的那条是怎么说的」，答案只在你的笔记里找。
4. 聊久了话题串了 —— 点「清空会话」，重新开始。
5. 记错了、情况变了 —— 去个人档案改掉那一条，不会留下前后矛盾的旧记录。

---

## 你的资料，你说了算

- 档案可以逐条查看、编辑、删除
- 对话可以一键清空
- 知识库里的文件和生成的简历都可以删除
- 关掉知识查询窗口，那段问答不会留下

所有轻提示都安静地一闪而过，不打断你正在做的事。
